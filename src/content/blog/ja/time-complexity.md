# 時間計算量をわかりやすく解説：初心者向けランダウの記号（Big O記法）

情報科学において、同じ問題を解くアルゴリズムには複数のアプローチが存在します。どの解法が最も優れているかを客観的に比較するために、入力サイズ（$N$）の増大に伴う処理ステップ数のスケールを表す**Big O記法（ランダウの記号）**を用います。

---

## 1. Big O記法とは？

Big O記法は、最悪ケースにおけるアルゴリズムの計算ステップ数の上限を数学的にモデル化したものです。実行端末のCPU性能（秒数）に依存せず、入力サイズ $N$ に対する計算量の漸近的挙動を評価します。

---

## 2. よく登場する計算量の分類

### 定数時間：$O(1)$
入力サイズ $N$ の大きさに関わらず、常に一定のステップ数で完了します：
```cpp
int getFirstElement(int arr[], int size) {
    return arr[0]; // 常に1回のアクセスで完了、O(1)
}
```

### 線形時間：$O(N)$
入力サイズ $N$ に比例して実行ステップ数が増加します：
```cpp
void printAllElements(int arr[], int n) {
    for (int i = 0; i < n; i++) {
        std::cout << arr[i] << std::endl; // N回ループ、O(N)
    }
}
```

### 対数時間：$O(\log N)$
探索ステップごとに探索範囲が半分になる二分探索（Binary Search）などに代表される極めて高効率な計算量です。

### 2次時間：$O(N^2)$
バブルソートや2重ループ処理など、入力数が増えるにつれて急速に重くなる計算量です。

---

## 3. 計算量を見積もる黄金律

- 定数項は無視する：$O(3N + 5) \rightarrow O(N)$
- 最大次数の項のみを残す：$O(N^2 + N) \rightarrow O(N^2)$
