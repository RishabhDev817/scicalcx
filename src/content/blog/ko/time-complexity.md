# 시간 복잡도 완벽 이해: 초보자를 위한 빅오(Big O) 표기법

컴퓨터 과학에서는 입력 데이터 크기($N$)가 증가할 때 연산 횟수가 어떻게 증가하는지 나타내기 위해 **빅오 표기법(Big O Notation)**을 사용합니다.

---

## 1. 주요 시간 복잡도 분류

- **$O(1)$ (상수 시간):** $N$의 크기와 무관하게 1번의 연산으로 종료 (예: 배열 인덱스 접근).
- **$O(N)$ (선형 시간):** $N$에 비례하여 실행 시간이 증가 (예: 단순 1차원 반복문).
- **$O(\log N)$ (로그 시간):** 매 단계마다 탐색 범위가 절반으로 줄어듦 (예: 이진 탐색).
- **$O(N^2)$ (2차 시간):** 중첩 반복문 (예: 버블 정렬).
